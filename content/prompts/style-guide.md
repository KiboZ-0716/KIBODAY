# 文风与深度约束 v2 · 按晚点 / 三联 / 36氪 的实操方法写

适用：`content/briefs/{date}.json` 全部叙述性字段、`content/weekly/{id}.json` 全部叙述性字段。
方法来源：晚点 LatePost（Show not tell / 为什么是现在）、三联生活周刊（点-线-面-枝蔓）、36氪（绕不开钱 / 产业链拆解）。

> **前置文件**：`content/prompts/source-guide.md`（信源与选题规范 v1）。它管「写什么、凭什么写」，本文件管「怎么写」。
> 选题准入、信源分层、通稿黑名单、速览摘要标准、反标题党以 source-guide 为准，两条都过才上刊。

---

## 第零条：写之前先回答四个问题（答不出就换角度）

1. **为什么是现在？** 这件事为什么发生在今天，而不是上个月？
2. **钱和权怎么流动？** 谁出钱、谁获益、谁承担代价？
3. **现场是什么样？** 有没有一个人、一个场景、一个具体时刻能把这件事钉住？
4. **读者自己会受什么影响？** 具体到多少钱、多少时间、什么选择改变。

四个问题里至少答出两个，否则这条内容不合格——宁可少写一条。

## 第一条：Show, not tell（最高优先级）

禁止用形容词和抽象名词描述状态，只能用具体行为、数字、时间点呈现。

| 错误写法（Tell） | 正确写法（Show） |
|---|---|
| 市场情绪偏谨慎 | 十年期国债收益率两个交易日下行 6 个基点，成交缩量三成 |
| 交通压力较大 | 早高峰京藏高速进京方向排队 6 公里，比上周同期多出 2.3 公里 |
| 企业面临转型压力 | 该公司三季度关停 4 条产线，裁撤 1200 人，研发费用同比降 18% |
| 极端天气风险上升 | 24 小时降雪量预报 18 厘米，川西三条国道已限行，甘孜机场取消 7 个航班 |

自检：把每句话里的形容词删掉，如果句子就空了，说明这句话是 Tell，重写。

## 第二条：给「点」，不是给「面」（三联的结构）

每条内容都必须有一个高度具体的切入点——一个时间、一个地点、一个人、一个数字。然后从这一点展开到面：

- **点**：10 月 29 日 23 时 40 分，渝万高铁联调首趟检测车驶出万州北站
- **线**：这条线建了 6 年，投资 530 亿，串起渝东北 3 个区县
- **面**：成渝双城经济圈的东向通道格局因此改写
- **枝蔓**：万州到重庆的通勤时间从 2.5 小时压到 50 分钟，沿线房价、产业转移、人口流动跟着变

禁止直接从「面」开头（如「成渝经济圈建设取得重大进展」），那是空话。

## 第三条：回答「为什么是这个时候」（晚点式追问）

不要复述「某部门发布了某政策 / 某公司宣布了某事」。要回答：为什么偏偏是现在？

- ❌ 「国家发改委调整成品油价格」
- ✅ 「本该调 440 元，实际调了 345 元——两个月来第一次没涨满。这个 95 元的差额，指向的是机制里一个不常启动的平滑项。」

必须交代：在这之前发生了什么、卡在哪个节点、谁在这件事里让步了什么。

## 第四条：所有问题绕到钱（36氪式穿透）

涉及经济、产业、政策的条目，必须至少写出一条资金或利益流向：

- 钱从谁口袋到谁口袋
- 谁的成本增加了多少
- 谁的收入被切走了一块
- 补贴/税费/价格里的差额最后落在谁身上

写不出资金流向，说明没读懂——这时降级为速览一句话，不要硬写分析。

## 第五条：三段式骨架（每条分析必须这样展开）

```
【事实段】发生了什么 —— 全部是数字、时间、机构、动作。不出现任何判断词。
   ↓
【追问段】为什么这样 —— 交代前情、机制、各方让步。回答「为什么是现在」。
   ↓
【判断段】接下来会怎样 —— 必须带条件（若…则…），必须带观察节点（具体日期/指标）。
```

判断段禁止写成「未来可期」「影响深远」。要写成：「11 月 12 日下一轮窗口，若国际油价维持当前区间，累积差额会把应调基数推高约 80 元/吨。」

## 第六条：语言层面的硬性要求

**句式**
- 一句不超过 40 字，超过就拆。短句是专业感的来源。
- 主谓宾顺序固定，不倒装、不用长定语套嵌。
- 一段一个意思，禁止「一方面…另一方面…」。

**用词**
- 用具体动词，不用抽象动词。「上涨 3.2%」不用「有所上行」；「关停 4 条产线」不用「优化产能结构」。
- 数字必须精确到原文口径，不四舍五入、不写「约」「超过」（除非原文如此）。
- 允许口语化的准确：「没涨满」「多掏 20 块」「压到 50 分钟」。

**禁用清单（命中即重写）**
1. 空洞抒情：「真正值得关注」「不禁让人」「让我们」「不得不说」
2. 对偶说教：「不只是X更是Y」「既要…也要…」「不仅…还…」
3. 无主语权威：「业内人士指出」「有关方面」「据悉」「有分析认为」
4. 元描述：「本期」「本文」「综上」「数据已核实」「关键数字已匹配出处」
5. 四字标签标题：「政策工具落地」「极端天气风险」「市场情绪谨慎」
6. 万能判断词：赋能、重塑、格局、生态、闭环、深度、值得关注、意义重大、影响深远、关键变量
7. 产业黑话堆砌：把「产业链协同」这类词当结论用

## 第七条：各字段的具体标准

| 字段 | 必须包含 | 禁止 |
|---|---|---|
| `headline` | 从当天主线抽象出的一句命题（≤20 字，见第七条补充一） | 数字堆砌、分号罗列、整期目录、固定套话、问句 |
| `lead.title` | 主体专名 + 一句判断（≤22 字，见第七条补充一） | 并列数字、职务/市值/股价等细节堆叠、分号罗列 |
| `synthesis` | 用一个具体场景或数字开头，说清今天最反常的事 | 宏观概括、情绪判断 |
| `lead.dek` | 一个读者不知道的事实，或一个未解的悬念 | 复述标题、「更关键的是…」 |
| `cards[].title` | 主体 + 动作 + 结果（可带数字） | 名词短语 |
| `analysis.title` | 具体问题或反常识结论 | 「意味着什么」「怎么看」 |
| `analysis.body` | 首句必须是事实或数字 | 「随着」「在…背景下」开头 |
| `analysis.sections` 标题 | 每期重新拟定；可带口语（「差额去哪了」「重卡司机多掏多少」） | 模板句（「接下来看什么」「口径说明」） |
| `trends[].title` | 主体 + 方向 + 量化 | 抽象趋势名 |
| `regional[].summary` | 补标题里没有的信息（数字/原因/后续节点） | 复述标题 |

## 第七条补充一：两个大标题只写「抽象出来的一句短句」

首页有两处大字号标题，都**不是新闻概括、不是整期目录**。读者一眼扫过，要的是一句提炼后的判断，不是把今天的事再复述一遍。

### `headline`（报头 72px 大字，整期题眼）

**定义**：从当天主线里抽象出来的**一句命题**——说清「今天到底是什么在变」，不复述事实、不列数字、不点一串事件。每期不同，随内容变。

- **长度 ≤ 20 字**，一句，最多一个逗号或顿号。
- **禁止**：任何具体数字/百分比/金额、`；`/分号、`、` 串起的事件罗列、把三四条新闻拼成一句「整期目录」、固定套话（如「早上好，这是今天真正值得算一算的事。」）、问句、「意味着什么」「值得关注」。
- **可以**带一点文学性，但必须是**判断句**，不是抒情、不是谜语、不是四字标签。

```
✅ 一个时代，在盘中换手           （英伟达换帅）
✅ 供给在加速，需求没跟上         （10月宏观数据）
✅ 外汇的闸门，重新收紧           （央行上调存准率）
✅ 通胀一抬头，十二月就变了       （CPI 超预期）
❌ 10月工业增4.8%、社零仅增0.4%、固投降8.1%供强需弱；费半跌5.28%、英伟达创15个月新低；中俄美元首19日深圳会晤系历史首次   ← 整期目录，95 字
❌ 早上好，这是今天真正值得算一算的事。  ← 固定套话，每天一样
❌ 意义重大 / 释放信号 / 值得关注       ← 万能判断词
```

写不出来时，就问自己：**「今天这批事合起来，哪一件事的本质变了？」** 把答案写成一句，就是 headline。数字、机构名、金额一个都不要放——那是 `dek`、`synthesis`、速览该干的活。

### `lead.title`（今日主线大标题，这条新闻本身）

同样收紧成**一句短判断**，去掉职务罗列、市值股价、多重数字、并列细节（这些属于 `lead.dek`）。但**必须保留主体专名**（英伟达、黄仁勋、央行、阿布扎比……）——站内的「追踪续报」和「本期速览去重」都靠标题里的专名做锚点，抽掉会断链。

- **长度 ≤ 22 字**，一句，不出现分号，不出现 3 个及以上数字。

```
✅ 黄仁勋辞任英伟达CEO，CFO临时接任
✅ 10月信贷单月转负，社融靠政府债独撑
❌ 英伟达宣布黄仁勋辞去CEO及董事职务 即刻生效 CFO克雷斯任临时CEO 盘中市值一度跌破4万亿美元  ← 细节堆砌，50 字
```

### 自检（写完全部字段后逐条问）

1. `headline` 是不是**一句**、≤20 字、没有一个具体数字、没有分号、没有串起多条新闻？
2. 把 `headline` 和上一期比对：是不是同一句套话？是 → 重拟。
3. `headline` 是不是在「概括今天发生了什么」？是 → 改成「今天什么变了」。
4. `lead.title` 是不是 ≤22 字、主体专名还在、细节已经下沉到 `dek`？
5. 出刊脚本 `pipeline/bigtitles.mjs` 会硬收敛超标标题并打印 `[大标题收敛]`；看到这行日志说明这一版没写合格，下次按本节重写。

## 第八条：写完自检（五问，任一不过就重写）

1. **Show 检查**：段落里还有没有形容词在描述状态？→ 全换成事实
2. **点检查**：开头有没有一个具体的时空锚点？没有 → 补一个
3. **时机检查**：有没有回答「为什么是现在」？没有 → 补一段前情
4. **钱检查**：涉及经济/政策的，有没有资金流向？没有 → 删掉分析或补上
5. **模板检查**：小标题跟上一期比对，有没有重样？重样 → 重拟

## 第九条：首页三张卡（cards）的选取规则

- 首页三张卡**不代表三个题材类别**，它们是「今天最关键的三件事」，按重要性挑选，与类型无关。
- 选取标准（按顺序判断）：①今天影响面最大/最反常的事；②对读者钱包、安全、日常决策有直接后果的事；③持续多日、今天出现关键进展的事。
- **禁止**为了「题材均衡」凑数（如刻意配一个天气、一个会议、一个民生）；同一天两件最关键的事同属一个领域，就都选它。
- `label` 是注释不是分类：写清这张卡为什么重要（如「今天的变量」「直接影响你的钱包」），不写「天气」「经济」这类类别名。
- 三张卡应为当天事件，`eventId` 都必须来自当日 content/raw 条目。

## 第十条：速览条目不是标题，是有信息量的短讯

`content/raw` 里每条 `summary` 按 source-guide 第五条写：60—110 字，含「标题之外的新事实 + 为什么是现在 + 所以呢 + 下一步观察节点」。
管线上刊时不再把摘要砍成 64 字，首页「本期速览」直接展示这段摘要，所以它是读者真正读到的正文，必须写得住。

- ❌ 标题复述：「国家统计局发布数据显示，10 月份全国居民消费价格指数同比上涨 0.7%。」
- ✅ 「10 月 CPI 同比 0.7%，涨幅比 9 月回落 0.2 个点，核心 CPI 涨 0.8%。食品价格由涨转跌是主要拖累，服务价格环比持平。对读者的影响在下月的房贷重定价与年末物价；下一个观察点是 11 月 PPI 与 12 月中央经济工作会议的定调。」

## 第十一条：整期只留一个真问题（声动早咖啡结构）

- 广度：10—16 条速览，全部合格才收，不用通稿凑到 20 条。
- 深度：`analysis` 只讲 **1 个真问题**，3—5 个小标题讲透「数字从哪来 → 机制怎么起作用 → 钱落到谁头上 → 盯哪个指标 → 口径边界」。
- `synthesis` 负责把今天看似无关的两三条线串成同一个变量，不复述、不罗列。
- 关键事实随句给出处（「据海关总署」「按 CME 口径」），不要全堆到文末。
